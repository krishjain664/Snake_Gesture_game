# Snake_Gesture_game
Basic Snake Game where the motion is controlled by hand gestures 
Used pyhton libraries like Mediapipe and open-cv for video capture and gesture detection
Also used threading as we need to run the Web-cam as well as the pygame interface simultaneously

*How To Play*
1)Make Sure your Camera is Turn On and Positioned properly to view your hand.
2)Run the File
3)Point upwards for up,right for right and similarly in all directions.
